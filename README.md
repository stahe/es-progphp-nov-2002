# Introducción a la programación web en PHP4

🔗 Curso original:
[https://stahe.github.io/es-progphp-nov-2002/](https://stahe.github.io/es-progphp-nov-2002/)

## Resumen

Este repositorio contiene **materiales didácticos dedicados a la programación web con PHP4**.
Se trata de un documento educativo diseñado para apoyar la enseñanza y no es un curso exhaustivo.

El documento permite a los estudiantes descubrir los fundamentos de la programación web en PHP y proporciona un recurso para sus ejercicios y experimentos.

## Origen del documento

Este material se deriva directamente del curso **«Introducción a la programación web en Java»**.
Se ha conservado la estructura didáctica, pero los ejemplos y las soluciones se han **adaptado a PHP**.

De este modo, para un lector familiarizado con **Java y PHP**, es posible comparar:

* una solución en Java
* una solución en PHP

para **el mismo problema de programación web**.

## Objetivos de aprendizaje

Este recurso tiene como objetivo:
* Introducir los fundamentos de la programación web del lado del servidor
* Presentar ejemplos concretos de código PHP
* Servir como base de trabajo para los estudiantes
* Permitir una comparación educativa entre Java y PHP

## Notas

* Este documento es **material didáctico**, no un manual exhaustivo.
* Algunos temas **no se tratan o solo se introducen brevemente**.
* **Para profundizar en el tema se requiere la orientación de un instructor**.

A pesar de ello, la información presentada permite a los alumnos **trabajar de forma independiente** en la mayoría de los casos. 

## Destinatarios:

Este documento está destinado principalmente a:
* **estudiantes que se inician en la programación web**
* personas que deseen **comparar los enfoques de Java y PHP**
* alumnos que utilizan PHP en un entorno educativo
